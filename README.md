# Mad Liquid: Rescate en el Infierno

Juego run-and-gun estilo Cuphead basado en el canal. Un solo archivo HTML (`mad-liquid-rescue/index.html`), sin dependencias.

## Historia
Mr110, harto de las burlas, secuestra a **Mad Liquid** y se lo lleva al infierno. **2patata** y **Tiamant** van a su rescate y en el camino se enfrentan a los enemigos que secuestraron a Liquid:

1. **Seguidores del canal** — hordas fanáticas
2. **Pokex** (el millonario)
3. **Mientrasleo** (la patriarca)
4. **Oxagoat** (la cabra)
5. **Mr110** (señor del infierno) — jefe final

## Cómo jugar
Abre `mad-liquid-rescue/index.html` en cualquier navegador.

- **1 / 2**: elegir personaje (2patata / Tiamant)
- **Flechas / WASD**: mover
- **Espacio**: saltar
- **Z**: disparar
- **SHIFT**: dash
- **ENTER**: avanzar menús / reintentar
